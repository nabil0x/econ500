## Exam Pattern (MSc 501 — 70 marks, answer any 5 from 8)

| Topic | Likely Questions | Priority |
|-------|-----------------|----------|
| **Consumer Theory** | 2–3 questions (preference axioms, duality, convexity proofs) | ⭐⭐⭐ |
| **Production & Supply** | 2 questions (production sets, full CD analysis, competitive eq) | ⭐⭐⭐ |
| **Welfare & Pareto** | 1–2 questions (CV/EV/CS, Hicks-Kaldor, welfare theorems) | ⭐⭐⭐ |
| **General Equilibrium** | 1 question (Edgeworth box or existence/stability) | ⭐⭐ |
| **Demand / Trade** | 0–1 question (elasticities or tariff — rotating topic) | ⭐ |

**Question types**: ~35% essay, ~25% proof, ~25% numerical, ~10% graphical, ~5% game theory

## Exam Day Checklist — Most Repeated Questions

These have appeared in **2+ sources** — highest probability:

- [ ] Preference-based approach + assumptions
- [ ] Strong monotonicity ⇒ downward sloping ICs
- [ ] Convexity ⇔ USC convex ⇔ quasiconcave
- [ ] SM ⇒ M ⇒ LNS hierarchy
- [ ] Cobb-Douglas: Walrasian demand + Roy's identity + Shephard's lemma
- [ ] CV/EV/CS definitions + CD computation
- [ ] EV > CS > CV for normal goods
- [ ] Pareto necessary but not sufficient for SW maximization
- [ ] Hicks-Kaldor compensation + Scitovsky double test
- [ ] GUPF + point of bliss
- [ ] GE existence / uniqueness / stability
- [ ] External shock transmission mechanism
- [ ] Production set properties
- [ ] Profit function properties (closed + free disposal)
