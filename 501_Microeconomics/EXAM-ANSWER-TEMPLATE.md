# 14-Mark Answer Structure Template

> **Time per question:** ~12 minutes (14 marks). Use this. Not optional. Learn it before exam day.

---

## Phase 1: Plan (2 minutes)

**Do NOT skip this.** Most point loss comes from answering the wrong question well.

| Step | Action |
|------|--------|
| 1 | Read the question. Circle the **topic** (preferences? welfare? GE? production?) and the **technique** (Lagrangian? diagram? proof? essay comparison?) |
| 2 | Jot down: key formula, diagram axes, chain of reasoning (3-5 words each) |
| 3 | Decide: can I answer fully, or do I need a partial answer strategy? If stuck, note the nearest related topic and pivot |

**The 3-second question classifier:**
- "Define/Explain/Compare" → **Theory/Definition** (emphasise parts A, D, E)
- "Derive/Compute/Find" → **Derivation/Numerical** (emphasise parts B, C, D)
- "Discuss/Evaluate/Does X maximise Y?" → **Essay/Evaluation** (emphasise parts D, E, with quick A)

---

## Phase 2: Write (10 minutes)

### (a) Definition / Setup — 2 marks (~1.5 min)

State the key concept. Define terms. List assumptions.

**Template:**
> By [concept], we mean [precise definition]. Following [author/year], [assumptions] hold because [brief justification].

**Checklist:**
- [ ] Defined every variable you will use
- [ ] Stated all assumptions explicitly
- [ ] Named the relevant theorem or approach

### (b) Mathematical Derivation — 4 marks (~3 min)

Set up the problem. Write the system. Derive the result.

**Template:**
> Set up the [optimisation/equilibrium]: [Lagrangian / system of equations].
> FOCs: [first-order conditions].
> Solving: [key result].

**Checklist:**
- [ ] Correct objective function written
- [ ] Constraints written correctly
- [ ] FOCs derived (not just stated)
- [ ] Solved for the key variable
- [ ] Second-order condition noted (if relevant)

### (c) Diagram / Graphical Analysis — 4 marks (~3 min)

Draw, label, explain. The diagram is worth its own marks.

**Template:**
> Figure 1 shows [what the diagram depicts]. The [curve/line] [label] represents [meaning]. The key insight is [what the diagram reveals].

**Checklist:**
- [ ] Axes labelled with variable names
- [ ] Every curve labelled
- [ ] Equilibrium points shown
- [ ] Arrows or shading for changes/areas
- [ ] Caption explains what the diagram proves

### (d) Intuition & Economic Interpretation — 2 marks (~1.5 min)

Translate the maths into plain English.

**Template:**
> Economically, [result] occurs because [intuition]. The mechanism is that [mechanism]. In words: [one-sentence summary].

**If you have 30 seconds left, this section gets you the marks.** Examiners use it to separate students who memorised algebra from those who understand economics.

### (e) Evaluation / Extensions / Connections — 2 marks (~1 min)

Link to broader course themes. Note a limitation or edge case.

**Template:**
> This result connects to [other topic / question] because [connection]. A limitation is [caveat / edge case]. For instance, if [assumption] is relaxed, [consequence].

**Cross-reference power move:** Mention a specific question number from another topic (e.g., "See also: GE Q3 on excess demand formulation"). This signals you see the course as a connected whole.

---

## Phase 3: Review (2 minutes)

| Check | Question |
|-------|----------|
| **Relevance** | Did I answer the actual question asked, or a related one? |
| **Diagram** | Are all axes, curves, and equilibrium points labelled? |
| **Variables** | Did I define every symbol before using it? |
| **Algebra** | Any sign errors? Did I drop a term? |
| **Cross-ref** | Can I add a "See also" for bonus polish? |

**If you find a mistake:** Cross it out cleanly and write the correction. Do not waste time erasing.

## Question Type → Structure Map

Which sections to emphasise depends on what you are asked.

| Question Type | Example | Emphasise | Rush / Skip | Mark Strategy |
|---|---|---|---|---|
| **Theory / Definition** | "Define and compare GE and PE" | A (definitions + comparison table), D (intuition), E (connections) | B (skip heavy maths), C (simple diagram only) | Get A perfect (first 2 marks are free). Make the comparison table crisp. |
| **Derivation / Numerical** | "Derive Walrasian demand for CD utility" | B (full derivation), C (diagram if relevant), D (intuition on result) | E (keep brief, one sentence only) | B is where the marks live. Show every algebraic step. |
| **Proof** | "Prove convexity ⇔ quasiconcavity" | A (definitions), B (both directions), D (why this matters) | C (no diagram), E (short) | Chain the equivalences explicitly. Both directions or zero credit on the proof part. |
| **Essay / Evaluation** | "Does perfect competition maximise social welfare?" | A (setup), D (intuition, heavy), E (extensions, heavy) | B (light maths only), C (one core diagram) | Structure as: claim → model → result → caveat. Two thirds of marks are in the evaluation, not the model. |
| **Comparison** | "Distinguish CV, EV, CS" | A (table of definitions), C (diagram of areas), D (intuition on ordering) | B (keep derivation minimal), E (one-liner) | The comparison table is the centrepiece. Then a diagram showing the ordering. |
| **Diagram-Heavy** | "EV > CS > CV: show graphically" | C (full diagram, centrepiece), A (brief definitions), D (intuition) | B (skip unless calculation asked), E (short) | Spend 5-6 minutes on the diagram. Every axis, curve, and shaded area must be labelled. |

## Worked Example 1: Theory / Definition

**Question:** "Define and compare general equilibrium and partial equilibrium."

**Phase 1 plan (2 min):** Topic = GE vs PE. Technique = comparison table + chain diagram. Key formula: none needed. Axes: P vs Q for a single market vs interconnected markets.

**Phase 2 write (10 min):**

**(a) Definition / Setup (2 marks):** By general equilibrium we mean a state where all markets and all decision-making units clear simultaneously. By partial equilibrium we mean analysis of a single market in isolation, holding all other markets fixed (ceteris paribus).

**(b) Mathematical Derivation (4 marks):** Keep light. PE: one equation QD(P) = QS(P). GE: system of N equations, one per market, with prices relative (numeraire good sets the price level). Excess demand formulation: E_i(p) = 0 for all i simultaneously.

**(c) Diagram / Graphical Analysis (4 marks):** Draw two panels. Panel 1: standard D-S cross for a single market (PE). Panel 2: interconnected markets diagram showing spillovers. Label the feedback loop: shock to market X → factor market → market Y → back to market X.

**(d) Intuition & Economic Interpretation (2 marks):** PE is a useful shortcut when cross-market effects are small. But when markets are tightly linked, ignoring feedback loops can give misleading policy predictions. The key difference: GE captures interdependence; PE treats it as negligible.

**(e) Evaluation / Extensions / Connections (2 marks):** This connects to the Arrow-Debreu existence proof (GE Q1) and the 2x2x2 model (GE 6B). A key limitation: GE models quickly become computationally intractable, which is why PE is still widely used in empirical work.

## Worked Example 2: Derivation / Numerical

**Question:** "Derive Walrasian demand for Cobb-Douglas utility u = x1^a x2^(1-a)."

**Phase 1 plan (2 min):** Topic = UMP. Technique = Lagrangian. Key formula: MRS = p1/p2. Axes: x1 vs x2 with IC and BC.

**Phase 2 write (10 min):**

**(a) Definition / Setup (2 marks):** The utility maximisation problem (UMP) is: choose x1, x2 to maximise u(x1,x2) subject to the budget constraint p1 x1 + p2 x2 = w. Assume strict monotonicity so the constraint binds.

**(b) Mathematical Derivation (4 marks):** Set up L = x1^a x2^(1-a) + lambda(w - p1 x1 - p2 x2). FOCs: (i) a x1^(a-1) x2^(1-a) = lambda p1, (ii) (1-a) x1^a x2^(-a) = lambda p2, (iii) budget constraint. Divide (i) by (ii): [a/(1-a)] * [x2/x1] = p1/p2 → x2 = [(1-a)/a] * (p1/p2) * x1. Substitute into budget: p1 x1 + p2 * [(1-a)/a] * (p1/p2) * x1 = w → x1(p,w) = a w / p1. Then x2(p,w) = (1-a) w / p2. Check: both are homogeneous of degree 0 in (p,w) as required.

**(c) Diagram / Graphical Analysis (4 marks):** Draw indifference curve and budget line. Show tangency condition MRS = p1/p2 at optimum (x1*, x2*). Label the BC intercepts (w/p1, w/p2) and the optimal bundle.

**(d) Intuition & Economic Interpretation (2 marks):** CD demand says expenditure share on each good is constant: a goes to good 1, (1-a) to good 2. This is because CD utility has constant expenditure shares by construction. This implies unit income elasticity and unit own-price elasticity.

**(e) Evaluation / Extensions / Connections (2 marks):** This result connects to the expenditure function via duality (EMP gives the same result). A limitation: constant expenditure shares are unrealistic for most real goods. The LES (Stone-Geary) relaxes this by adding subsistence requirements.

## Worked Example 3: Essay / Evaluation

**Question:** "Does perfect competition maximise social welfare?"

**Phase 1 plan (2 min):** Topic = welfare theorems. Technique = essay with diagram. Key formula: MB = MC at competitive equilibrium. Axes: P vs Q with D, S, shaded surplus areas.

**Phase 2 write (10 min):**

**(a) Definition / Setup (2 marks):** By perfect competition we mean: price-taking firms, homogeneous goods, free entry/exit, perfect information. By social welfare we mean total surplus = consumer surplus + producer surplus. The first welfare theorem states that every competitive equilibrium is Pareto efficient.

**(b) Mathematical Derivation (4 marks):** Market equilibrium: QD(P*) = QS(P*). Consumer surplus = integral from P* to choke price of QD(p) dp. Producer surplus = integral from 0 to P* of QS(p) dp minus fixed costs. Welfare = CS + PS. At competitive P*, the sum is maximised because P* = MC = MB for the marginal unit.

**(c) Diagram / Graphical Analysis (4 marks):** Draw D and S crossing at (P*, Q*). Shade CS (triangle above price, below D) and PS (triangle below price, above S). Show that at any Q < Q*, the MB of an extra unit exceeds MC (deadweight loss triangle). At any Q > Q*, MC exceeds MB (another DWL triangle).

**(d) Intuition & Economic Interpretation (2 marks):** Competition maximises welfare because price equals marginal cost. Each unit produced generates value (measured by the demand curve) that exceeds its cost (measured by the supply curve), and production stops where these are equal. No mutually beneficial trade is left unexploited.

**(e) Evaluation / Extensions / Connections (2 marks):** This result depends on strong assumptions: no externalities, no public goods, no market power, perfect information, no income distribution concerns. The second welfare theorem says any Pareto efficient outcome can be supported as a competitive equilibrium with appropriate lump-sum transfers, separating efficiency from equity. In practice, real-world deviations (monopoly, pollution, asymmetric information) create scope for welfare-improving intervention.

## Common Time Traps

| Trap | Why it kills you | Solution |
|------|------------------|----------|
| **Over-deriving** | Spending 6 minutes on algebra for 4 marks, leaving 1 minute for 4 marks of diagram | Timebox derivation to 3 minutes. If not done, sketch the result and move on. |
| **Diagram before definitions** | Drawing a beautiful diagram but losing the first 2 marks because you never defined the terms | Force yourself: define first, then draw. The 2 + 4 ordering is deliberate. |
| **The "everything I know" dump** | Writing everything about a topic regardless of what the question asked | Check Phase 1 plan: what technique does the question demand? Answer only that. |
| **No cross-reference** | Losing 2 easy marks at the end because you did not link to other topics | Keep 30 seconds for a "See also" sentence. It is the highest-leverage use of time. |
| **Perfectionism on a partial answer** | Spending 8 minutes on the part you know, then having 2 minutes for 6 marks you could have scored | If stuck on a sub-part, write a one-sentence answer and move on. Partial credit is real. |
| **Wrong technique** | Setting up a Lagrangian when the question asks for a diagram (or vice versa) | The Phase 1 "technique" check prevents this. Never skip it. |
| **Algebra panic** | Making a sign error, then spending 3 minutes trying to find it | Circle your final answer. If it looks wrong (e.g., negative price), write "sign check failed, structure is correct" and keep going. |
