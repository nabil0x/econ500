## Key Textbooks (Not Included)

The recommended textbooks for Advanced Macroeconomic Theory are:
- **Romer, David** — *Advanced Macroeconomics* (the primary reference)
- **Acemoglu, Daron** — *Introduction to Modern Economic Growth*
- **Barro, Robert & Sala-i-Martin, Xavier** — *Economic Growth*

These textbooks cover all 7 topics in the 502 syllabus (Solow, Ramsey, Endogenous Growth, OLG, R&D, RBC, New Keynesian).
